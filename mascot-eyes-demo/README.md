# Маскот: слежение глазами

Откройте index.html — демо работает без установки и сервера.

Источник: Figma, фрейм 3336:208. Точное изображение и векторные слои экспортированы из макета. Белки и тело не изменены. Двигаются только группы «глаз левый двигать тут» и «глаз правый двигать тут».

Для сайта вставьте mascot-original.svg как inline SVG, импортируйте attachMascotEyes из mascot-eyes.js и вызовите функцию с этим SVG. Движение ограничено маской белка. На сенсорном устройстве маскот статичен.
